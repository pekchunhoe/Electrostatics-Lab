# Magnetic trajectory physics fix — investigation and validation

Implemented and tested locally on 18 October 2026 (Asia/Kuala_Lumpur). Target: Uniform Electric Field → Experiment D → Magnetic Force. This report updates the magnetic launch policy, demonstration defaults and validation conclusions in `DYNAMIC_EQUILIBRIUM_VALIDATION.md`.

1. **Observed root causes.** Before editing, the repository was clean. An actual browser reproduction selected D, Magnetic, horizontal plates and doubled B using the existing numeric control. The default had E_y = +9810 N/C, B_z = −0.20 T, q = 1e−9 C and m = 1e−6 kg. Its unconstrained E×B initializer produced **vx = −49050 m/s**, launching leftward near the left plate end. Reproduction evidence is preserved in [magnetic-trajectory-before.json](magnetic-trajectory-before.json) and the two `before-*.png` images in [the screenshot directory](screenshots/magnetic-trajectory-fix/).

   Doubling B to 0.40 T preserved velocity and produced a_y = −9.81 m/s². After about 0.5 real seconds, the physical timer was 4.40366972477e−7 s, x = −0.1416 m, y = −9.51192660550e−13 m, and vy = −4.32e−6 m/s. The actual painted centre matched that displacement. The force was changing velocity; the transverse movement was **1.45396592398e−9 CSS pixels**, far below visible resolution. The leftward launch also reached the nearby field end quickly.

2. **What was physically negligible and what was defective.** The ordinary default-case apparent straight line was caused by an unsuitable combination of mass, charge, field, speed and observation interval. The analytic flow was already producing the small transverse motion; no persistent balanced-trajectory shortcut was found in that reproduction. The new defaults address observability with real SI parameters. The audit separately found and repaired two actual boundary/history defects:

   - At an exact open-end tangent start, historical entry classification used the **latest** B instead of the initial field epoch. A subsequent field reversal could therefore alter the reconstructed past position and velocity. In the reproduced edge case, recomputing the same 0.001 s instant changed vy from 1.99760014666 to 1.99960001333 m/s and y by approximately 1e−6 m. Initial classification now uses the historical B; a regression asserts continuous position and velocity while the current magnetic force reverses.
   - With E = B = 0, skipping redundant electric-region transitions could miss a straight grazing collision with a finite plate's end corner. A particle starting at (−0.2, +0.1) m, vx = 500 m/s, L = d = 0.2 m incorrectly reached x = +0.3 m without contact. Both orientations now stop at the corner after exactly 0.0002 s. This geometric contact check introduces no force.

4. **Rightward initial velocity.** Fresh horizontal Magnetic mode starts at x0 = −0.4L, y0 = 0 with **v0 = (+500, 0) m/s**. The first visible magnetic example uses q = ±1 nC, preserving the chosen charge sign, m = 1e−13 kg, downward E = 100 N/C, B = 0.20 T into the page, and the existing gap/length. Its notice explicitly states the chosen parameters. D’s precise mass input now accepts 1e−7–1000 mg, including the required 1e−13 kg reference; the A–C mass range is unchanged. Zero charge remains a separately labelled trivial force case.

   Horizontal initial speed is positive; vy is shown as a read-only zero component. Invalid negative/zero horizontal speed edits are rejected. Replay preserves the chosen fields and restores the rightward initial launch. Reset retains Magnetic selection and reloads its balanced example. Returning from vertical to horizontal retains Magnetic mode, starts toward the left end and explicitly initializes a compatible B direction. **Only initialization is constrained.** The evolving velocity is unrestricted; numerical and browser orbit tests include negative current vx.

5. **Balance compatibility and vertical behavior.** For horizontal rightward motion, B_z must have the same sign as E_y to oppose the electric force. Fresh downward-E defaults use into-page B. An upward-E orientation preset explicitly selects out-of-page B. Later manual field/polarity reversals preserve the initial rightward velocity and are allowed to break balance.

   If the selected B direction would require leftward motion, Balance explains the incompatibility without changing fields or velocity. **Match B to Rightward Launch** is a separate explicit direction action; it preserves B magnitude and speed. Balance then adjusts only initial speed to E/B. With E = 0 and nonzero B, no positive horizontal speed can balance the magnetic force, and this is explained. B = 0 and zero charge retain their explicit handling. Fresh vertical Magnetic mode uses rightward E, into-page B and upward velocity; later vertical presets use the tangent direction required by the actual fields.

6. **Authoritative Lorentz state and solver.** World coordinates remain +x right, +y up, +z out. The actual motion follows ax = (q/m)(Ex + vy Bz), ay = (q/m)(Ey − vx Bz). The existing exact uniform-field propagator was audited against a separate drift-and-rotation solution and retained. It propagates coupled position/velocity analytically, using stable small-angle quotients and the correct B = 0 limit. Boundary searches split coordinates into monotone intervals and localize events with bisection. The historical-entry and zero-field corner checks above are the solver repairs.

   Each magnetic result now carries the force snapshot evaluated from its **current position, instantaneous velocity and field epoch**, including FE, FB, resultant and acceleration. Force arrows, equilibrium status and component displays consume that same snapshot. The visible particle and trajectory samples use the same exact propagation engine. No force magnitude subtraction substitutes for vector addition, and signed q is retained throughout.

16. **Limitations.** This is an ideal planar classical Lorentz model with abrupt electric boundaries, prescribed uniform B, no fringing/inductive electric field, and absorbing point-particle plate contact. The visible disk radius is used for full-canvas visibility, while collision physics uses the particle centre as before. Deliberately chosen weak q/m or very large radius can still yield physically tiny visible deflection; those user parameters are respected. Magnetic-only orbits can remain visible indefinitely and use the labelled time limit. Extreme boundary encounter sequences retain the existing 200,000-search guard. Desktop Chromium with emulated touch/viewports was tested; physical phones, Firefox and Safari/WebKit remain unverified.
